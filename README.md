# 🐈 JUST A CAT

> Apparently, someone has to run this house.

A cozy browser life-sim made as a game-development society recruitment project.

## 🎮 Concept

You are a cat living alone while your human is away.

You need to:
- Eat
- Rest
- Clean the apartment
- Water plants
- Cook
- Shop
- Manage energy and hunger
- Deal with random cat events
- Survive 14 days

The fun twist: **you are still a cat.**

The cat can get distracted, enter cardboard boxes, knock things over, watch birds, nap instead of working, and develop a personality based on how you play.

## 🛠️ Tech

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas
- No backend
- No external dependencies

## ▶️ Run locally

Simply open `index.html` in a modern browser.

For development, VS Code + Live Server is recommended.

## 🚀 Deploy to Vercel

1. Upload the project to GitHub.
2. Go to Vercel.
3. Import the GitHub repository.
4. Framework preset: **Other**.
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Deploy.

## 🎤 Interview pitch

“JUST A CAT is a cozy life-management game where the player controls a cat that has to manage a household while its human is away. The core design challenge was making the cat feel like a character rather than just an avatar. So I added unpredictable cat behavior, environmental changes, resource management, gardening, cooking, random events, and a personality system based on player behavior.”
